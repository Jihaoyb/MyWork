# Provisional suggestions and experiments

These are recommendations, not confirmed decisions. No unanswered question authorizes implementation. Source: PRD-update.md §3–4 unless noted.

| ID | Suggestion | How to evaluate / revisit |
| --- | --- | --- |
| P01 | Trial one important session per day for one week of actual use. | Review usefulness and burden after actual use, not elapsed calendar sessions. Missed days never fabricate trials. |
| P02 | Five-minute entry action inside an initial 25-minute session; stopping after entry is allowed. | Ask whether this helps starting and preserves concentration; offer deliberately chosen deeper work. |
| P03 | Start check-in about 10 seconds, close about 20–30 seconds. | Observe effort with consent; these are burden hypotheses, not demonstrated timings. |
| P04 | Evening reconciliation shows unresolved sessions only, taking at most one minute. | User can leave unknown outcomes unresolved; avoid duplicate journaling. |
| P05 | Boundary choices: Wrap up, Pause, or a bounded extension fitting commitments. | Test stopping usefulness and annoyance; no silent extension or completion. |
| P06 | Start smaller, snooze to a chosen time, or skip today; optional reasons. | Trial clear, brief, supportive wording; respect dismissal and user-controlled reminders. |
| P07 | Save tangents with context; short lookup only when needed for the current step. | Evaluate whether return to work is easier; saved interests never become obligations. |
| P08 | Local browser milestone before hosted delivery. | Assistant recommendation during initialization: reduces setup; cannot provide cross-device use. Await user answer. |
| P09 | Judge first-week value primarily by resuming without replanning. | Assistant recommendation: matches the core acceptance target; await user priority. |

Timing and reminder behavior must be configurable before trials depend on them. Dashboard-only delivery remains confirmed. There are no clinical prescriptions, new notification channels, or scheduled automations here. Change one setting at a time after reviewing experience; record evidence and user ratification in DECISIONS.md.
